## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
git clone https://github.com/KumarVishal91/KisanAI.git
cd KisanAI
npm install
```

### Development

```bash
npm run dev
```

This starts the Vite dev server with hot module replacement.

### Build

```bash
npm run build
```
